# Ordinary Zen Coffee

A cinematic, Japanese-inspired coffee brand landing page built with React, Three.js, GSAP ScrollTrigger, and Tailwind CSS.

## Run locally

```bash
cd website
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The existing repository root contains the upstream GSAP library source. This website lives in its own `website/` directory so the original library files remain untouched.
